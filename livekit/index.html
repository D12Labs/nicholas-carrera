Open source work, for LiveKit

@livekit/components-react 2.9.24 throws on import when an AMD loader is present. I reproduced it and fixed it in one line.

Issue: livekit/components-js#1428. The release before it (2.9.23) works; 2.9.24 is still latest on npm. Everything below was run on Node 22 against the published packages and a build from main (commit 1ce6ca0).

Before and after

2.9.23, published
OK: imported
2.9.24, published
TypeError: Ms.default.getLogger is not a function
main, built from source
TypeError: xs.default.getLogger is not a function
main + the one-line fix
OK: imported with define.amd

All four use the same 10-line script with a global define.amd set. Without define.amd, both published versions import fine, so only AMD-loader environments are affected.

Reproduce it yourself

npm i @livekit/components-react@2.9.24 livekit-client react react-dom --legacy-peer-deps
node repro.mjs   # repro.mjs: sets define.amd, then imports the package

Root cause

The package bundles loglevel, which ships as a UMD wrapper. The 2.9.23 build had that wrapper resolved at build time, so no AMD check survives in its output. The 2.9.24 build keeps the check live:

typeof define == "function" && define.amd ? define(r) : typeof t == "object" ...

Wherever a global define.amd exists, module.exports is never assigned, .default is an empty object, and getLogger is not a function. The build config moved to Vite 8, so I am treating the bundler change as the likely trigger, not a confirmed one.

The fix

   ],
+  // Bundled UMD deps (loglevel) must take their CommonJS branch regardless of a global AMD
+  // loader at runtime; otherwise module.exports is never assigned (livekit/components-js#1428).
+  define: { 'define.amd': 'undefined' },
   build: {

What I tried first, and why I dropped it

I first externalized loglevel in the Rollup options. It still threw (Ei.getLogger is not a function), because loglevel's own UMD wrapper takes the same AMD branch. A fix that only passes a happy-path check is not a fix, so I kept going until the repro itself passed.
